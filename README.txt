SPOORTI RAJ - MOVIE TICKET BOOKING STATIC WEBSITE
RUN: Extract this ZIP and open index.html in Chrome.
PAGES: Home, Movies, Theatres, Offers and Book Tickets.
FILES: HTML pages, css/style.css, js/main.js.
This is a static front-end mini project using HTML, CSS and JavaScript. The booking page has interactive seat selection and demo price calculation (₹180 per seat). No real movie database, theatre inventory, payment gateway or booking server is connected; no real tickets are issued. Movie titles, theatre names, locations, timings and offers are sample data. Images and Google Fonts load from the internet.
